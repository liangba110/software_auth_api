# 软件授权支付平台 · 对接文档（softapi）

> 版本：v1.0（2026-08-28）
> 面向：各软件开发者 / Trae AI 编程助手

---

## 一、平台概述

本平台为多软件提供**用户体系 + 微信自动充值 + 权限自动开通**一站式服务。每款软件注册后获得独立身份（app_id/app_key），接入后：

- 用户注册 / 登录 / 鉴权全自动
- 微信扫码支付 → 支付成功自动开通 VIP 权限（日卡/月卡/年卡/永久）
- 权限到期自动失效
- 支付结果自动回调通知软件服务器

## 二、基础信息

| 项目 | 值 |
|---|---|
| API 基础地址 | `https://softapi.openai2000.cn` |
| 收银台地址 | `https://softapi.openai2000.cn/pay/{app_id}/` |
| 在线接口文档 | `https://softapi.openai2000.cn/docs` |
| 支付方式 | 微信 Native 扫码（统一支付网关） |
| 数据格式 | JSON（UTF-8） |
| 传输安全 | 全站 HTTPS |

## 三、接入流程（三步）

```
第1步：软件注册 → 获得 app_id + app_key（保存好，app_key 只显示一次）
第2步：你的软件接入用户注册/登录/下单接口（带签名）
第3步：配置 notify_url 接收支付成功回调
```

## 四、接口签名机制（重要）

除 `register`、`info`、`page/*` 外，所有接口必须携带签名。

### 4.1 签名算法

```
sign = md5( app_id + 参数拼接 + app_key + timestamp )

参数拼接规则：
1. 取请求参数中除 sign、timestamp 外的所有参数
2. 按参数名 ASCII 升序排序
3. 拼接为 key1value1key2value2... 形式（app_id 也参与）
4. 最后拼上 app_key 和 timestamp
```

### 4.2 Python 示例

```python
import hashlib, time, requests

def md5(s: str) -> str:
    return hashlib.md5(s.encode()).hexdigest()

def signed_post(path: str, params: dict, app_id: str, app_key: str) -> dict:
    params = dict(params)
    params['app_id'] = app_id
    timestamp = str(int(time.time()))
    keys = sorted(params.keys())  # 排除 sign/timestamp（此时还没加）
    raw = params['app_id'] + ''.join(f'{k}{params[k]}' for k in keys) + app_key + timestamp
    params['sign'] = md5(raw)
    params['timestamp'] = timestamp
    r = requests.post(f'https://softapi.openai2000.cn{path}', json=params, timeout=15)
    return r.json()
```

### 4.3 JS/Node 示例

```js
const crypto = require('crypto');

function signedPost(path, params, appId, appKey) {
  params.app_id = appId;
  const ts = String(Math.floor(Date.now()/1000));
  const keys = Object.keys(params).sort();
  let raw = params.app_id;
  for (const k of keys) raw += k + params[k];
  raw += appKey + ts;
  params.sign = crypto.createHash('md5').update(raw).digest('hex');
  params.timestamp = ts;
  return fetch('https://softapi.openai2000.cn' + path, {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify(params)
  }).then(r => r.json());
}
```

> ⚠️ timestamp 与服务端相差超过 300 秒（5分钟）签名失效。

## 五、API 接口列表

### 1. 软件注册（获取 app_id/app_key）

- **POST** `/api/app/register`
- 无需签名

请求：
```json
{
  "app_name": "我的软件",
  "notify_url": "https://myserver.com/pay/notify",
  "logo_url": "https://myserver.com/logo.png"   // 可选
}
```

响应：
```json
{
  "code": 200,
  "msg": "注册成功，请妥善保存 app_key",
  "data": {
    "app_id": "APP1787923178330",
    "app_key": "3d7b68a89aa72e8915d3282183029bd1"
  }
}
```

### 2. 软件信息（公开）

- **GET** `/api/app/info?app_id=xxx`

响应：
```json
{ "code": 200, "msg": "操作成功",
  "data": { "app_id": "APP...", "app_name": "我的软件", "logo_url": null } }
```

### 3. 软件用户注册

- **POST** `/api/app/user/register`
- 需签名

请求：
```json
{
  "app_id": "APP...",
  "username": "user01",
  "password": "mypass123",
  "sign": "32位md5",
  "timestamp": "1787923178"
}
```

响应：
```json
{ "code": 200, "msg": "注册成功", "data": { "user_id": 1 } }
```

### 4. 软件用户登录

- **POST** `/api/app/user/login`
- 需签名

请求：
```json
{
  "app_id": "APP...",
  "username": "user01",
  "password": "mypass123",
  "sign": "...",
  "timestamp": "..."
}
```

响应：
```json
{
  "code": 200, "msg": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user_id": 1,
    "username": "user01",
    "vip_type": 0,
    "vip_expire_time": null
  }
}
```

### 5. 登录鉴权 / 权限校验（客户端启动时调用）

- **GET** `/api/app/user/auth?app_id=xxx&token=xxx`

响应（权限正常）：
```json
{
  "code": 200, "msg": "权限正常",
  "data": { "user_id": 1, "username": "user01",
            "vip_type": 2, "vip_expire_time": "2026-09-27 21:20:05" }
}
```

响应（权限过期）：
```json
{ "code": 403, "msg": "权限已过期", "data": null }
```

响应（未登录）：
```json
{ "code": 401, "msg": "登录已过期", "data": null }
```

> 💡 客户端启动 → 调此接口 → code=200 且 vip_type>0 解锁付费功能；403 则锁定。

### 6. 充值下单（返回微信支付二维码）

- **POST** `/api/app/recharge/create`
- 需签名

请求：
```json
{
  "app_id": "APP...",
  "token": "用户登录返回的token",
  "goods_type": 2,
  "sign": "...",
  "timestamp": "..."
}
```

goods_type 说明：
| goods_type | 套餐 | 价格 | 权限时长 |
|---|---|---|---|
| 1 | 日卡 | ¥9.9 | 1天 |
| 2 | 月卡 | ¥29.9 | 30天 |
| 3 | 年卡 | ¥199.9 | 365天 |
| 4 | 永久 | ¥520 | 永久 |

响应：
```json
{
  "code": 200, "msg": "下单成功",
  "data": {
    "order_sn": "SA217879231982933",
    "amount": 29.9,
    "pay_url": "weixin://wxpay/bizpayurl?pr=5QQN5boeYbizX2Lw"
  }
}
```

> `pay_url` 是 `weixin://` 链接，**直接用它生成二维码**（勿替换域名），用户微信扫码即付。

## 六、支付成功回调（notify_url）

用户支付成功后，平台会 **POST** 到你注册时填写的 notify_url。

### 6.1 回调格式（JSON）

```json
{
  "app_id": "APP...",
  "order_sn": "SA2...",
  "amount": 29.9,
  "goods_type": 2,
  "user_id": 1,
  "status": 1,
  "timestamp": "1787923205",
  "sign": "32位md5"
}
```

### 6.2 回调验签

```
sign = md5( app_id + amount29.9 + goods_type2 + order_snSA2... + status1 + timestamp... + user_id1 + app_key + timestamp )
```
即：`md5(app_id + amount{amount} + goods_type{goods_type} + order_sn{order_sn} + status{status} + timestamp{timestamp} + user_id{user_id} + app_key + timestamp)`

### 6.3 接收方要求

- 返回 HTTP 200 即视为成功；失败会重试（间隔递增，最长24小时）
- 收到回调后：验签 → 校验订单号 → 给用户开通对应软件功能

### 6.4 Python 回调示例

```python
from flask import Flask, request
import hashlib

app = Flask(__name__)
APP_KEY = '你的app_key'

@app.route('/pay/notify', methods=['POST'])
def notify():
    data = request.json
    ts = data['timestamp']
    raw = (data['app_id'] + f"amount{data['amount']}" + f"goods_type{data['goods_type']}"
           + f"order_sn{data['order_sn']}" + f"status{data['status']}"
           + f"timestamp{ts}" + f"user_id{data['user_id']}" + APP_KEY + ts)
    if hashlib.md5(raw.encode()).hexdigest() != data['sign']:
        return 'sign error', 403
    # 验签通过 → 给用户开权限
    print('用户', data['user_id'], '支付成功', data['amount'])
    return 'ok'
```

## 七、完整对接时序

```
你的软件客户端              你的软件服务器              平台(softapi)
    │                           │                        │
    │  ① 启动调 /user/auth       │                        │
    ├───────────────────────────> (转发到平台,带token)      │
    │                           ├───────────────────────>│
    │                           │  返回 vip_type/过期时间  │
    │                           │<───────────────────────│
    │  ② 用户点充值 → 调 /recharge/create                 │
    │                           ├───────────────────────>│
    │                           │  返回 order_sn+pay_url  │
    │                           │<───────────────────────│
    │  ③ 展示微信二维码(扫描支付)                            │
    │                           │                        │
    │  ④ 用户微信扫码支付完成                                │
    │                           │                        │
    │  ⑤ 平台回调 POST → 你的notify_url                   │
    │                           │<───────────────────────│
    │                           │  验签→开通用户权限        │
    │  ⑥ 客户端轮询 query 或重新 auth → 权限生效            │
```

## 八、错误码

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数错误 / 业务错误（msg 说明）|
| 401 | 未登录 / 登录过期 / 软件无效 |
| 403 | 签名无效 / 账号封禁 / 权限过期 |
| 404 | 资源不存在 |
| 500 | 服务端异常 |

## 九、注意事项

1. **app_key 务必保密**：只在软件服务端使用，切勿下发到客户端（否则签名可被伪造）
2. **签名时效 5 分钟**：timestamp 用服务器当前时间
3. **订单号前缀 SA2**：是平台路由标识，勿修改
4. **二维码**：pay_url 直接生成二维码，不要替换 `weixin://` 前缀
5. **回调幂等**：同一订单可能收到多次回调，需按 order_sn 判重
6. **未支付订单 30 分钟失效**，超时需重新下单
7. 每软件用户体系独立（A 软件用户不能登录 B 软件）
